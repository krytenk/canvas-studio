# Print and digital product roadmap

The detailed baseline assessment is [USEFULNESS-ASSESSMENT-2026-11-01.md](USEFULNESS-ASSESSMENT-2026-11-01.md). It describes version 1.1.0, not the corrected current behaviour. Acceptance scenarios are in [WORKFLOW-ACCEPTANCE.md](WORKFLOW-ACCEPTANCE.md).

| Stage | Status | Scope |
| --- | --- | --- |
| 1. Trustworthy starter editor | Implemented; automated and PDF proof checks added | Exportable template defaults, complete selection copy/transform, size-aware page insertion, checked SVG/HTML and accurate local-tool descriptions. Manual desktop acceptance remains open. |
| 2. Useful personal print studio | Started in 1.2.0 | Implemented personal masters with tags/previews/search and independent copies; point size/leading/tracking/overflow controls; numeric geometry and print-first defaults. Imported static TrueType faces added in 1.3.0. Paragraph spacing, insets and mixed character styles added in 1.4.0. Guides, single-file delivery and saved output presets added in 1.5.0. Foundations implemented; complete-product and manual acceptance remain open. |
| 3. Product production | In progress | Fields, shared styles, embedded field photos and background CSV production implemented in 1.6.0. Page organisation, book masters/folios/margins, background artwork placement and a 50-page acceptance fixture added in 1.7.0. Core production workflows implemented; native/physical acceptance remains open. |
| 4. Specialist product tools | Planned | Validated puzzles/answers, activity-book controls and reproducible product recipes. |
| 5. Customer editing | Optional later milestone | A chosen recipient editing format or browser editor, tested independently of the creator's computer. |

Stages are accepted through completed product workflows, not through the existence of toolbar controls. Keep changes incremental and preserve old document compatibility.

Next implementation target: seeded word searches, independently checked placements/answer keys, editable puzzle/solution pages and reusable puzzle recipes.
